Introduction

Welcome to the Amortia programming language documentation! Amortia is a functional programming language designed with simplicity and expressiveness in mind. This guide will help you learn the language from the ground up.

Amortia compiles to Erlang, giving you access to the powerful BEAM virtual machine with its excellent concurrency and fault-tolerance capabilities, while providing a clean, modern syntax.

Getting Started

Installation

To get started with Amortia, you'll need the Amortia compiler installed on your system. Currently the only way of installing Amortia is by compiling the source code using Stack.

$ Shell 
 git clone https://github.com/laluxx/amortia
 cd amortia
 stack build
 stack install
💡 NOTE

Make sure to put ./local/bin in path that's where stack installs by default. Add this to your ~/.bashrc export PATH="$HOME/.local/bin:$PATH"

Amortia requires Erlang to be installed on your system since it currently compiles to it. At some point it will compile to BEAM bytecode directly, making Erlang not a dependency

Your First Program

Let's start with the classic "Hello, World!" program. Create a file called hello.amor and add the following code:

Amortia 
defn main :: () {
    display "Hello, World!~n"
    halt 0
}

Compile and run your program:

Shell 
$ amortia hello.amor
$ ./hello

Syntax Basics

Functions

Functions in Amortia are defined using the defn keyword, followed by the function name, type signature with ::, and the function body enclosed in curly braces. Functions use pattern matching to handle different cases.

Amortia 
defn last :: [a] -> a {
    [] -> error badarg
    [x] -> x
    [_|xs] -> last xs
}

defn main :: () {
    display last [1, 2, 3, 4, 5]
    halt 0
}

Pattern Matching

Pattern matching is a powerful feature that allows you to destructure data and handle different cases elegantly. Let's break down the last function line by line:

Amortia 
defn last :: [a] -> a {
    [] -> error badarg
    [x] -> x
    [_|xs] -> last xs
}

Line by line explanation:

  • defn last :: [a] -> a - Defines a function named last that takes a list of any type [a] and returns a single element of that type a.
  • [] -> error badarg - First pattern: if the list is empty, signal an error with the badarg atom, since there's no last element in an empty list.
  • [x] -> x - Second pattern: if the list contains exactly one element x, return it. This is the base case that stops the recursion.
  • [_|xs] -> last xs - Third pattern: if the list has at least one element, ignore the first element (using _ wildcard) and recursively call last on the remaining elements xs.

Here's a more complex example with multiple pattern clauses and guards:

Amortia 
defn kth :: [a] -> Int -> a {
    [] _ -> error badarg
    [x|_] 0 -> x
    [_|xs] n, when n > 0 -> kth xs n-1
    _ _ -> error badarg
}

defn main :: () {
    display kth [1,2,3,4] 2
    halt 0
}

Pattern matching happens from top to bottom:

  • [] _ -> error badarg - If the list is empty, signal an error with the atom badarg
  • [x|_] 0 -> x - If the index is 0, return the first element (head)
  • [_|xs] n, when n > 0 -> kth xs n-1 - If index is positive, recursively call with tail and decremented index. The when clause adds a guard condition
  • _ _ -> error badarg - Catch-all for invalid cases (negative indices)

Lists and the Cons Operator

Lists are fundamental data structures in Amortia. The cons operator | is used to both construct and destructure lists.

Deconstructing Lists

The pattern [x|xs] splits a list into its head x (first element) and tail xs (remaining elements):

Amortia 
defn head :: [a] -> a {
    [] -> error badarg
    [x|_] -> x
}

defn tail :: [a] -> [a] {
    [] -> error badarg
    [_|xs] -> xs
}

defn main :: () {
    display head [1,2,3]
    display "~n"
    display tail [1,2,3]
    halt 0
}

You can also match multiple head elements:

Amortia 
defn compress :: [a] -> [a] {
    [] -> []
    [x] -> [x]
    [x,x|xs] -> compress [x|xs]
    [x|xs] -> [x] ++ compress xs
}

defn main :: () {
    display compress [1,1,1,2,2,3,4,4]
    halt 0
}

The pattern [x,x|xs] matches when the first two elements are identical, allowing us to skip duplicates.

Constructing Lists

You can also use | to construct lists by prepending elements:

Amortia 
-- These are equivalent:
[1, 2, 3]
[1|[2, 3]]
[1|[2|[3|[]]]]

Tail Recursion

Tail recursion is a special form of recursion where the recursive call is the last operation in the function. The BEAM VM optimizes tail-recursive functions to use constant stack space, making them efficient for processing large datasets.

Here's a non-tail-recursive function:

Amortia 
defn len :: [a] -> Int {
    [] -> 0
    [_|xs] -> 1 + len xs  -- NOT tail recursive (addition after call)
}

And here's the tail-recursive version using an accumulator:

Amortia 
defn len :: [a] -> Int {
    list -> len_helper list 0
}

defn len_helper :: [a] -> Int -> Int {
    [] acc -> acc
    [_|xs] acc -> len_helper xs acc+1  -- Tail recursive!
}

defn main :: () {
    display len [1,2,3,4,5]
    halt 0
}

The pack function is another great example of tail recursion with an accumulator:

Amortia 
defn pack :: [a] -> [[a]] {
    [] -> []
    list -> pack list []
}

defn pack :: [a] -> [[a]] -> [[a]] {
    [] acc -> reverse acc
    [x|xs] [] -> pack xs [[x]]
    [x|xs] [[x|group]|rest] -> pack xs [[x,x|group]|rest]
    [x|xs] acc -> pack xs [[x]|acc]
}

defn main :: () {
    display pack [1,1,1,2,3,3,4]
    halt 0
}
💡 TIP

When writing recursive functions, always consider if they can be made tail-recursive using an accumulator. Tail-recursive functions are more memory-efficient and won't cause stack overflow errors on large inputs.

Lambda Functions

Lambdas (anonymous functions) are created using the backslash \ operator. They are useful for passing functions as arguments to higher-order functions.

Amortia 
defn main :: () {
    doubled = map \x -> x * 2, [1,2,3,4,5]
    display doubled
    halt 0
}

The syntax is \parameter -> expression. The comma after the lambda separates it from the remaining arguments to map.

Type System

Basic Types

Amortia has several built-in types:

Type Description Example
Int Integer numbers 42, -17, 0
String Text strings "Hello"
Bool Boolean values true, false
[a] Lists of type a [1, 2, 3]
() Unit type (no value) ()

Type Signatures

Functions in Amortia must declare their types using :: notation. Type variables (lowercase letters like a, b) represent generic types that can be any type.

Amortia 
-- Function taking no arguments, returning nothing
defn main :: () {
    display "Hello"
    halt 0
}

-- Function taking a list of any type, returning an Int
defn len :: [a] -> Int {
    [] -> 0
    [_|xs] -> 1 + len xs
}

-- Function taking two arguments of the same type
defn kth :: [a] -> Int -> a {
    [x|_] 0 -> x
    [_|xs] n -> kth xs n-1
}
